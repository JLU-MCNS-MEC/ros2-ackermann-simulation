## 端到端视觉导航里程碑

用户目标是 `RGB 图像 + 目标 -> 速度/转向`，不是只把深度转成 Nav2 障碍点。
激光雷达继续负责独立安全停车；视觉模型不能绕过速度平滑器与 Collision Monitor。

- [x] V0：建立 Nav2 示范采集、OpenCV 小型行为克隆训练、影子推理、误差统计和
  实时图像叠加。第二批使用单发布者 `/cmd_vel_smoothed`，采集 697 组样本；链路通过，
  模型精度未达到接管门槛。
- [ ] V1：至少采集 10,000 组训练样本，覆盖双向行驶、不同起点、目标、光照、遮挡、
  动态物体和相机扰动；按路线而不是按相邻帧划分训练/验证/测试集。
- [ ] V2：将小型 MLP 替换为带时间上下文的 CNN/Transformer，优先复用 ViNT/NoMaD
  的目标条件视觉导航表示；固定权重、依赖和许可，提供 ONNX/TensorRT 运行接口。
- [ ] V3：影子模式至少完成 20 个未参与训练的目标；统计控制误差、碰撞风险、推理
  P95 延迟、图像断流和弱纹理/暗光退化，不通过时不得接管。
- [ ] V4：把合格模型实现为 Nav2 控制器插件或受监督控制源，保持
  `Nav2 -> velocity_smoother -> Collision Monitor -> /cmd_vel_safe -> drive`；先限速
  0.10 m/s，在封闭场景逐级验收，再允许提升速度。
- [ ] V5：增加目标图像和语言目标编码，支持“到办公桌旁”等语义指令；未知、歧义、
  不可见目标必须拒绝或请求确认，不能让语言模型直接绕过安全层输出底盘命令。

## 通用验收约束

- 每阶段补充公共函数正常、边界及错误测试，运行相关构建和测试。
- 导航实际运行记录与源码测试分别记录；不把 launch 可加载写成导航已通过。
- 初版命名地标允许人工标注，但必须标记来源，不能称为自动视觉语义建图。
- 场景真值只用于评估，不用于定位、自动识别或在线语义目标坐标生成。
- SLAM 首先人工指定目标覆盖空间；自动探索另行验收。
- 关键阶段独立 commit 并 push 到功能分支；不自动合并未验收功能到 main。
- 三维与开放词汇功能必须在二维闭环后继续实施，并单独验证依赖及算力。
