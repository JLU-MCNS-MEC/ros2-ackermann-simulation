# 位置优先目标路径优化实验

日期：2026-09-10。

## 问题与结论

车辆在没有明显障碍时仍可能绕远。检查全局代价地图后，车辆前方、侧向测试点和通道
目标之间的直线栅格代价均为 0，说明这些样本不是安全区过宽造成的。

Smac Hybrid-A* 使用 Reeds-Shepp 模型，车辆最小转弯半径为 0.9 m。Ackermann 车辆
不能横移或原地旋转；当 RViz 目标箭头指定了侧向或相反的最终朝向时，规划器必须增加
一段弧线，使车辆同时满足位置和朝向。

## 实现

新增 `goal_pose_optimizer`：

1. 订阅 RViz 的位置优先目标 `/goal_pose_auto`。
2. 查询目标坐标系下的实时 `base_footprint` 位姿。
3. 比较前进与倒车到达所需的初始转角，选择较短方向。
4. 仅更新目标朝向，并通过标准 `/goal_pose` 交给 Nav2。

原 `Nav2 Goal` 不变，用于必须精确控制最终车头方向的任务。新入口不改变障碍代价、
Collision Monitor 安全区、速度限制或物理最小转弯半径。

## 验证结果

固定车辆附近的侧向目标，目标直线距离约 1.200 m：

| 输入 | 规划路径 | 路径/直线比 | 结果 |
| --- | ---: | ---: | --- |
| 原始精确姿态 | 约 2.592 m | 2.16 | 仅规划对照 |
| 位置优先姿态 | 约 1.907 m | 1.59 | 27.56 s 实际到达 |

位置优先路径缩短约 26%，最终目标距离约 0.299 m。前方同朝向目标的规划路径与直线
距离一致；反向、侧向和要求相反终点朝向的目标仍会受车辆运动学约束，不保证成为直线。

源码测试覆盖前进、倒车、侧向、禁止倒车、近距离、无效输入、消息复制、缺失坐标系、
正常 ROS 转发和错误丢弃；相关 22 项测试通过，新模块覆盖率为 87%。完整工作区
3 个 ROS 2 包构建通过，171 项测试为 0 errors、0 failures、0 skipped。

重启完整 AMCL、Nav2、目标适配器和 RViz 后，从入口 `(0.13, 0.17)` 通过
`/goal_pose_auto` 导航到中央通道 `(4.01, 1.74)`，约 13.4 s 成功到达，没有触发恢复。
该轮同时确认位置优先话题只有一个发布者和一个订阅者，适配后的 `/goal_pose` 由
`bt_navigator` 唯一订阅。
