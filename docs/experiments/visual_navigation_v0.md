# V0 端到端视觉导航原型记录

日期：2026-09-10。范围：100 平方米仿真场景，RGB 图像和相对目标直接预测
`Twist`；激光、深度点云不作为模型输入。车辆控制权始终属于 Nav2。

## 实现

- `visual_dataset_recorder` 以 5 Hz 保存 RGB、图像采集时刻的相对目标和老师命令。
- `visual_policy_train` 用 OpenCV MLP 建立最小行为克隆基线，不增加 PyTorch 依赖。
- `visual_policy` 输出 `/visual_navigation/cmd_vel_shadow`，同步统计与老师的误差，发布
  带目标箭头和 `VISION/NAV2` 数值的调试图像。
- 无活动路径时调试图仍刷新并明确显示等待状态；相机断流时影子命令归零。

## 实际运行

首批 557 组数据使用 `/cmd_vel_nav`，发现该话题有 5 个发布者，不适合作为唯一老师，
因此保留为失败对照，不用于最终结论。第二批改用唯一发布者 `/cmd_vel_smoothed`：

- 5 个 Nav2 示范目标全部成功，0 次恢复；采集 697 组，约 11 MB。
- 64 次图像采样因采集时刻 TF 尚不可用而拒绝，没有使用最新 TF 代替。
- 数据清单 SHA-256：`19cf80b1d7a865085c4b87fe7e174f463358268687c66fbcdf4dc9eb9065dfff`。
- 模型 SHA-256：`265e5bc3a0d90369e6cd78cd8a709fcb6843d8daec5d0bb71fba2d53a0647350`。
- 139 组交错验证样本上，速度 MAE 约 0.040 m/s，角速度 MAE 约 0.093 rad/s。
- 3 个影子测试目标均由 Nav2 成功完成，0 次恢复；视觉输出约 3–4.2 Hz。
- 影子实时速度 MAE 0.119 m/s、角速度 MAE 0.139 rad/s，P95 分别为
  0.510 m/s、0.387 rad/s，明显不满足控制接管要求。

原始图像、模型、导航 JSON、影子指标和桌面截图位于被 Git 忽略的
`artifacts/validation/20260910/visual_e2e/`。

## 结论与限制

V0 证明了示范采集、训练、在线推理、误差统计和可视化数据流可运行，但没有证明端到端
视觉导航能够自主控制车辆。小型单帧 MLP 缺少时间上下文，数据规模小，测试路线与训练
路线也未严格隔离；当前记录器过滤长期静止标签，后续数据集还需加入数量受控的到达停车
样本。下一步按 V1–V3 扩展数据，并替换为 ViNT/NoMaD 类时序策略；只有
未见路线的影子验收通过后，才进入限速控制测试。
